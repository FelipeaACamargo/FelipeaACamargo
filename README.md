# Prof. Dr. Felipe A. Camargo


Atualmente atuo como docente no curso de Inteligência e Análise de Dados do Centro Universitário SENAI São Paulo (UniSENAI – Campus Suíço-Brasileira).

Sou Licenciado em Matemática pela UNESP (Campus de Presidente Prudente), Mestre e Doutor em Biometria pela UNESP (Campus de Botucatu), com atuação nas áreas de Matemática Aplicada e Computacional, Ciência de Dados e Modelagem Matemática.

Desenvolvo projetos envolvendo análise de dados, modelagem estatística, aprendizado de máquina e simulações computacionais, utilizando Python como principal ferramenta para pesquisa, ensino e desenvolvimento de soluções baseadas em dados.
